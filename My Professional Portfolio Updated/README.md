# Abul Hasin — Personal Portfolio

A responsive personal portfolio built with HTML, CSS and vanilla JavaScript. It presents my academic background, projects, skills, experience, achievements, certificates and selected photographs.

## Preview locally

Open `index.html` in your browser. For a local development server, use VS Code Live Server.

## Before publishing

1. Review `assets/abul-hasin-profile.webp` and replace it if you prefer another portrait.
2. Review the certificate and photograph gallery and remove anything you do not want public.
3. Review `assets/Abul-Hasin-CV.pdf` and replace it with an updated CV when needed.
4. Your contact email is already set to `abulhasinnumber@gmail.com`.
5. Verify academic dates, current CGPA, semester results, role titles, organization descriptions and award details.
6. Add direct repository and live-demo links for each project when available.
7. Confirm that every social link is correct before deployment.

## Deploy

This is a static website and does not require a backend. Upload the folder to Netlify, Vercel, or a GitHub Pages repository.

## Connect GitHub

- GitHub profile: https://github.com/abulhasin
- Create a new repository: https://github.com/new
- GitHub Pages documentation: https://docs.github.com/en/pages

To publish with GitHub Pages, create a repository named `abulhasin.github.io`, upload the contents of this folder to its `main` branch, then open **Settings → Pages** and select **Deploy from a branch → main → /(root)**.
